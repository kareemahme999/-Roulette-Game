# Roulette Game 🎰

A simple C# console game based on a roulette wheel.

## How to Play

The wheel randomly chooses a number from **1 to 4**:

* **1** → +1 point
* **2** → +2 points
* **3** → -1 point
* **4** → Nothing happens

You start with **0 points**.

### Goal

Reach **10 points** in less than **20 spins** to win.

If you don't reach 10 points within 20 spins, you lose.
